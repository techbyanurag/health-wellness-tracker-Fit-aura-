# WellTrack – Health & Fitness Tracking Web App
**WellTrack** is a simple and interactive **health & fitness tracking website** built using **HTML, CSS, and JavaScript**.  
It helps users monitor key fitness metrics like **BMI, steps, and calories**, while providing a smooth and user-friendly experience.

---

## ✨ Features

- **Landing Page (Index Page)**  
  - Clean introduction with a **Login button**.  
  - Displays **fitness-related articles** to motivate users.

- **Authentication**  
  - **Login** and **Signup** pages to create and access accounts.  
  - User data is securely stored in **JavaScript Local Storage** (no external database required).

- **Home Page**  
  - Displays key health stats: **BMI**, **step count**, and **calorie tracking**.

- **Profile Management**  
  - **Profile page** (accessible via menu) to **update personal details** anytime.

- **Logout Option**  
  - Securely **logs the user out** and redirects back to the **Login page**.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS  
- **Logic & Data Storage:** JavaScript (Local Storage)

---

## 🚀 How It Works
1. User lands on the **Index page** → clicks **Login**.  
2. After successful **login/signup**, the **Home page** loads.  
3. User can **update details** in the **Profile page**.  
4. On clicking **Logout**, the session ends and the user is taken back to the **Login page**.
